# Minecraft Whitelist Discord Bot

## Требования
- Node.js 22 или новее
- Discord application и bot token

## Установка
1. Распакуй проект в отдельную папку.
2. Выполни `npm install`.
3. Скопируй `.env.example` в `.env` и укажи `DISCORD_TOKEN`.
4. Заполни `config.json`: Discord guild ID, все ID ролей, ID администраторов.
5. В Discord Developer Portal включи **Server Members Intent** и **Message Content Intent**.
6. Запусти `npm start`.

## Выдача проходок
- `discord.access_role_ids` — перечисление всех ролей, выдача любой из которых автоматически запускает процесс платной проходки.
- `discord.role_access_types` — сопоставление каждой такой роли со значением `paid`. Бесплатные роли сюда добавлять не нужно.
- Бесплатная проходка выдаётся только вручную через `!панель`, без привязки к Discord-роли.
- Платная и бесплатная заявки используют одинаковую дальнейшую процедуру: ник → заявка администраторам → кнопка подтверждения.

## Пиратские/offline-mode серверы
- `minecraft.check_profile_exists` установлен в `false`: бот не обращается к Mojang/Minecraft для поиска профиля.
- Проверяется только допустимый формат ника Java Edition: 3–16 символов, латинские буквы, цифры и `_`. Это совместимо с никнеймами на offline-mode серверах.
- Форматная проверка не может подтвердить, что ник действительно занят конкретным игроком на сервере.

## Администраторы
- `discord.admin_ids` — кому отправлять заявки и кто может нажимать «Я добавил».
- `discord.panel_admin_ids` — кто может использовать `!панель`.

## Примечания
- Бот не добавляет игрока в whitelist самостоятельно: администратор добавляет игрока в Minecraft, затем нажимает кнопку подтверждения.
- Не публикуй `.env` и не отправляй токен другим людям.
